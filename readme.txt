Intructions on using the Jupyter Notebook

1. Using the widgets on the first tab or second tab, input the 
new data point's attribute values.

2. Click predict risk, and the left graph will display the risk the input
data is determined to be in blue.

3. The right graph shows where the inputted data lies in the existing
training dataset with a blue star.

Feature Importance

1. Feature importance can be used after inputting the new data in the first tab.

2. Click calculate importance and the results will display in a bar graph,
with each bar showing how much each attribute contributes to the risk
calculation.
